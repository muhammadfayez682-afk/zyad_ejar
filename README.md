# إيجاراتي

تطبيق ويب بسيط لإدارة المباني المؤجرة من الباطن: الوحدات، العقود، دفعات المستأجرين، الصيانة، والتقارير.

## التشغيل

ملف واحد `index.html` بدون خادم ولا تثبيت. فعّل GitHub Pages على الفرع الرئيسي وافتح الرابط من الجوال.

## البيانات

هذه النسخة تجريبية: البيانات تُحفظ في متصفح الجهاز نفسه (localStorage) ولا تُشارك بين الأجهزة. تُحمَّل بيانات تجريبية عند أول فتح.
